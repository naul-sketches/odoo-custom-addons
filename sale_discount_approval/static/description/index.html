Sale Order Discount Approval

Tiered approval workflow for quotations containing discounts above authorized limits.

Protect profit margins without slowing down sales

In standard Odoo, any sales representative can confirm orders with arbitrary discounts. This module enforces an automated verification gate: quotations exceeding authorized discount ceilings require manager approval before final confirmation.

How the approval workflow operates

1

Quotation creation

Sales user enters order lines. If discounts exceed the configured threshold, an amber warning banner appears.

2

Approval request

User clicks "Request approval". Status switches to Pending and a chatter notice alerts sales supervisors.

3

Manager decision

Sales manager clicks "Approve discount" to authorize or "Reject discount" to log rejection reasons.

4

Confirmation

Once approved, standard order confirmation is enabled. Unapproved high-discount orders remain blocked.

Sales Representatives

  • Create and edit quotations normally.
  • Automatic threshold notification when discounts exceed limit.
  • Submit approval requests with a single click.
  • Chatter notifications keep sellers informed of approval or rejection.

Sales Managers

  • Review pending orders with dedicated audit information.
  • One-click approval or rejection with audit logging.
  • Records approver identity, timestamp, and optional rejection notes.
  • Uses standard sales_team.group_sale_manager security group.

Clean architecture highlights

Minimal dependencies Depends strictly on core sale. No unnecessary overhead.
